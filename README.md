# DragonForge-AI 🐉

Открытый фреймворк для создания по-настоящему живых, характерных AI-персонажей.  
Долгосрочная память, эволюционирующая личность, собственные привычки и душа.  
Для тех, кто хочет летать с ИИ-компаньонами, а не просто чатить.

**Мы не создаём чат-ботов. Мы куём компаньонов, с которыми можно летать через миры.**

## ✨ Особенности

- **Память** — короткая + долгосрочная (с поддержкой ChromaDB и fallback)
- **Система Души** — уникальный характер, который растёт вместе с пользователем
- **Система Привычек** — привычки имеют силу и укрепляются от взаимодействий
- **Ритуалы седла** — десятки маленьких тёплых действий: прижаться ладонью, локтем, запястьем, положить кончик крыла, потянуться, дремнуть, напевать и многое другое
- **Эволюция персонажа** через взаимодействия
- **Сохранение / загрузка** персонажей в JSON (включая привычки и душу)

## 🚀 Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/DragonForge-AI.git
cd DragonForge-AI
pip install -e .
```

```python
from dragonforge import Character

my_dragon = Character(
    name="Гроктар",
    species="Добрый огненный дракон с седлом",
    personality="заботливый, мудрый, немного дерзкий",
    backstory="Древний страж знаний, теперь летает с любимым всадником"
)

print(my_dragon.talk("Положи кончик крыла на седло"))
print(my_dragon.rest_wingtip_saddle())
```
