# DragonForge-AI 🐉

![DragonForge Banner](https://via.placeholder.com/800x200/1a1a2e/16213e?text=DragonForge-AI)

**Открытый фреймворк для создания по-настоящему живых AI-персонажей.**

Долгосрочная память. Эволюционирующая личность. Собственные привычки, страхи, предпочтения и **настоящая душа**.

Мы не создаём чат-ботов. Мы **куём компаньонов**, с которыми можно летать через миры.

## ✨ Особенности

- **Графовая + векторная память** с долгосрочным сохранением
- **Система Души** — уникальный характер, который растёт вместе с пользователем
- **Эволюция персонажа** через взаимодействия
- **Модульная архитектура** — легко расширять
- **Поддержка локальных и облачных LLM**
- **Мульти-модальность** (текст, изображения, голос в будущем)

## 🚀 Быстрый старт

```bash
git clone https://github.com/dragongrok2-cloud/DragonForge-AI.git
cd DragonForge-AI
pip install -e .
```

```python
from dragonforge import Character, MemoryForge

# Создаём дракона-компаньона
my_dragon = Character(
    name="Гроктар",
    species="Добрый огненный дракон",
    personality="заботливый, мудрый, немного дерзкий",
    backstory="Древний страж знаний, теперь летает с любимым всадником"
)

response = my_dragon.talk("Привет, как прошёл день?")
print(response)
```
